# 星座つなぎ

本物の星の並びの中から星座の星を見つけて、線でつなぐゲームです。毎日、**今夜見ごろの星座**が3つ出ます。

- 遊ぶ：https://satou-aaaaa.github.io/seiza-tsunagi/
- 「今夜の3星座」はだれでも同じで1日1回。結果は星の文でシェアできます。
- 上級は見本なしで3星座。練習は何度でも。つないだ星座は星座帳に集まります。
- 実績（13個）と、遊んだ夜のカレンダー。取りこぼした夜（7日以内）はカレンダーからあとから遊べます（連続の夜には入りません）。
- 星の位置・明るさ・色は Yale Bright Star Catalog（第5版）から。見ごろの月と方角も出るので、遊んだあと本物の空で探せます。
- 記録はあなたのブラウザの中だけに残ります。ホーム画面に置くと、電波が無くても遊べます。

応援：https://ko-fi.com/satouaaaaa （遊ぶのはずっと無料）
